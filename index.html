My journey

I'm a Full-Stack Engineer who builds multi-tenant web platforms end to end: ASP.NET Core and NestJS APIs, Angular and React front ends, and the data, messaging and security layers that hold them together.

At Contellect I'm the main contributor to a NestJS microservices backend and have shipped 340+ merged pull requests on a .NET 9 system. I've added single sign-on across web, desktop and mobile apps, led a messaging upgrade across several services, and built interactive 3D warehouse views.

I also connect business systems to AI. I built a server that lets AI assistants work with a company's full API, and I engineer AI agent workflows to deliver faster. For 7agz, a sports-court booking app, I designed a multi-agent loop: an orchestrator hands each task to designer, developer, reviewer and tester sub-agents working in parallel, picks the right model for each task's difficulty, and only merges work that passes review and tests.
